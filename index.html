About FixerTools

FixerTools is a collection of free browser-based utilities built to make everyday digital tasks quicker. Each tool does one job: you enter your values, press a button and get the result.

The library is still growing. If there is a tool you would like to see, tell us through the contact form.

  • CalculatorsAge, percentage, BMI, discount, tip, loan EMI, GST and date difference.
  • Text toolsWord counter, case converter, duplicate line remover, slug and password generators.
  • ConvertersUnits, temperature, data size, time, binary, Base64 and URL encoding.
  • Developer and image toolsJSON formatter, HTML entities, HEX to RGB, image compress, resize and convert.
