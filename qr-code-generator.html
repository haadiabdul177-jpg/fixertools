Questions

Is this QR code generator free?

Yes. There is no sign-up, no watermark and no limit on how many codes you make.

Do my codes expire?

No. The code stores your text directly, so it works for as long as the link or details inside it stay valid.

Which colors scan best?

Use a dark code on a light background with strong contrast. Light code on a dark background fails on many scanner apps.

What does error correction do?

Higher levels let a code still scan when it is smudged or partly covered, but make the pattern denser. Medium suits most uses.
