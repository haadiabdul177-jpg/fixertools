Questions

What does a JSON formatter do?

It adds line breaks and indentation so JSON is easy to read. It also checks that the JSON is valid and points to the place where something is wrong.

What are the most common JSON errors?

A trailing comma after the last item, single quotes instead of double quotes, keys without quotes, and a missing comma or bracket. The error message above shows the line and column to check.

What does Minify do?

Minify removes all extra spaces and line breaks so the JSON takes up as little space as possible. This is useful for sending data or saving bandwidth.

Is my data uploaded?

No. Everything runs in your browser, so your JSON never leaves your device. You can safely paste private data.

Why did a very large number change?

Browsers read JSON numbers as standard floating point values, so whole numbers beyond 9,007,199,254,740,991 can lose precision. If you need exact large IDs, store them as strings.
